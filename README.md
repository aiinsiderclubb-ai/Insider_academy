# AI Insider Academy — платформа обучения

Платформа с видеокурсами по автоматизации, чат-ботам, голосовым агентам. LMS: каталог курсов, личный кабинет, админ-панель.

## Как открыть платформу и админку

**Платформа и админка работают только через dev-сервер.** Не открывайте `index.html` напрямую — так не заработает.

1. В папке проекта откройте терминал и выполните:
   ```bash
   npm install
   npm run dev
   ```
2. В браузере откройте: **http://localhost:5173** — откроется главная страница платформы.
3. Админ-панель: откройте **http://localhost:5173/admin** или ссылку «Админ» в подвале сайта. Пароль: **admin123**.

Подробнее: см. файл **КАК_ЗАПУСТИТЬ.md**.

## Что есть

- **Главная** — герой, блок «Что вы получите», превью курсов, призыв к действию
- **Каталог курсов** (`/courses`) — все курсы карточками
- **Страница курса** (`/courses/:slug`) — описание, список уроков, видео **доступны только после покупки** (покупка в демо — кнопка «Купить», без реальной оплаты)
- **Мой кабинет** (`/cabinet`) — для авторизованных; список купленных курсов и переход к просмотру

## Как добавить свои видео

В файле `src/data/courses.js` у каждого урока есть поле `videoUrl`. Подставьте туда прямую ссылку на видео (например, `.mp4`):

```js
{ id: 'a1', title: 'Введение...', duration: '15 мин', videoUrl: 'https://ваш-хостинг/lesson-1.mp4' },
```

Для YouTube/Vimeo можно доработать компонент `src/components/VideoPlayer.jsx` (embed iframe по ссылке).

## Демо-авторизация

«Войти» — по кнопке «Войти в кабинет» вводится email (сохраняется в `localStorage`). «Купить курс» — курс добавляется в список покупок того же пользователя (тоже в `localStorage`). Реальную авторизацию и оплату можно подключить позже.
