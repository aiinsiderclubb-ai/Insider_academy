# Как открыть платформу и админ-панель

## В чём может быть проблема

1. **Сервер не запущен** — платформа не открывается по файлам (двойной клик по `index.html`). Нужен запущенный dev-сервер.
2. **Не тот адрес** — нужно открывать в браузере именно **http://localhost:5173**, а не папку с файлами.
3. **Папка проекта с кириллицей** — путь вроде `платформа любимого` иногда мешает. Если ничего не работает, скопируйте проект в папку с путём только из латинских букв (например `C:\Projects\lms`).

---

## Пошаговый запуск

### 1. Откройте терминал в папке проекта

- В Cursor / VS Code: меню **Terminal → New Terminal** (или `` Ctrl+` ``).
- Либо откройте **PowerShell** или **cmd** и перейдите в папку проекта:
  ```bash
  cd "C:\Users\Юлия\Desktop\платформа любимого"
  ```

### 2. Установите зависимости (если ещё не ставили)

```bash
npm install
```

### 3. Запустите сервер

```bash
npm run dev
```

В терминале должно появиться что-то вроде:

```
  VITE v5.x.x  ready in xxx ms
  ➜  Local:   http://localhost:5173/
  ➜  press h + enter to show help
```

**Сервер должен оставаться запущенным** — не закрывайте это окно терминала.

### 4. Откройте платформу в браузере

- В браузере (Chrome, Edge, Firefox) откройте: **http://localhost:5173**
- Должна открыться главная страница AI Insider Academy.

### 5. Откройте админ-панель

- В том же браузере откройте: **http://localhost:5173/admin**
- Либо на любой странице платформы прокрутите вниз до подвала и нажмите ссылку **«Админ»**.
- Пароль для входа: значение `ADMIN_PASSWORD` из `server/.env` (минимум 12 символов, например `dev-admin-pass-1`)

---

## Если ничего не открывается

- Убедитесь, что в терминале нет красных ошибок после `npm run dev`.
- Проверьте, что в браузере введён именно адрес **http://localhost:5173** (с `http://`).
- Попробуйте другой браузер или режим «Инкогнито».
- Если порт 5173 занят, Vite может предложить другой (например 5174) — смотрите строку `Local:` в терминале и открывайте указанный там адрес.
