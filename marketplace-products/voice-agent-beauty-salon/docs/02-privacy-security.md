# Privacy and security

- Collect minimum data: name, phone, service and appointment time.
- Never request card data, health history or identity documents.
- Disclose recording before collecting personal data where recording enabled.
- Keep call audio off by default. Define retention before enabling.
- Use distinct staging/production secrets and numbers.
- Verify webhook signature before any calendar action.
- Use idempotency key for booking writes.
- Redact transcripts and summaries. Store call ID, not full transcript, when possible.
- Rotate secrets after team/agency handoff.
- Revoke calendar credentials when client relationship ends.
- Restrict n8n editor access; enable MFA and encrypted backups.

Local law and provider terms vary. Client must approve final notice, consent, retention and data-processing terms.
